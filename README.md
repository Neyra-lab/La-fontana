# La Fontana — Restaurant Website

A responsive multi-page restaurant website concept for **La Fontana Trattoria**, an Italian restaurant demo. Built to showcase front-end development, restaurant storytelling, menu presentation, and reservation/contact interfaces.

## Preview

> Add the live demo URL here when ready.

## Pages

- **Home** — hero section, restaurant introduction, and menu highlights
- **About** — restaurant story and values
- **Menu** — categorized Italian dishes with descriptions and prices
- **Contact** — contact form interface and restaurant information
- **Booking** — reservation form interface with date, time, and guest selection

## Features

- Responsive layout for desktop and mobile
- Multi-page navigation
- Intro animation and subtle UI motion
- Interactive navigation for smaller screens
- Form validation and client-side confirmation UI
- Semantic HTML and accessibility-minded form labels
- Google Fonts: Cormorant Garamond and Manrope

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

1. Clone or download this repository.
2. Open `index.html` in your browser, or use a local development server such as the VS Code Live Server extension.
3. Navigate through the pages using the site navigation.

## Important Note

This is a **front-end demo project**, not a live restaurant service. The booking and contact forms provide a user-interface demonstration; they do not send messages to a restaurant or store real reservations unless a backend or form-handling service is connected.

The restaurant name, contact details, address, opening hours, and menu are sample content for the demo.
